# Datvex prompt LAB

Benvenuti nel **Datvex prompt LAB**. Questo è un repository professionale e strutturato che contiene prompt di alta qualità in lingua inglese, progettati per compiti specializzati su molteplici sistemi di IA.

La collezione include prompt accuratamente selezionati provenienti da varie fonti della comunità globale di IA — inclusi repository GitHub, canali Discord e altre risorse professionali — oltre a prompt originali sviluppati specificamente per questo LAB.

---

## 📂 Navigazione
Sfoglia la libreria in base all'attività e al caso d'uso. In questa fase, tutti i collegamenti portano al database ufficiale curato:

*   [**✨ Ricerca prompt AI (NUOVO)**](https://datvex.github.io/Datvex-prompt-LAB/) – Ricerca intelligente alimentata dall'IA per trovare rapidamente i prompt perfetti per le tue esigenze.

---

## 🚀 Roadmap
Siamo in costante evoluzione per fornire le migliori risorse di prompting.

- [x] **Fase 1:** Lancio del database ufficiale curato (Attuale).
- [ ] **Fase 2:** Gli utenti possono aggiungere i propri prompt al database.
- [ ] **Fase 3:** **Creazione del generatore di prompt IA.** Sviluppo di uno strumento intelligente per generare prompt in base alle tue esigenze.
