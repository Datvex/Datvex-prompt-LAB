# Datvex prompt LAB

Bienvenido a **Datvex prompt LAB**. Este es un repositorio profesional y estructurado que contiene prompts de alta calidad en inglés, diseñados para tareas especializadas en múltiples sistemas de IA.

La colección incluye prompts cuidadosamente seleccionados de diversas fuentes de la comunidad global de IA —incluyendo repositorios de GitHub, canales de Discord y otros recursos profesionales— así como prompts originales desarrollados específicamente para este LAB.

---

## 📂 Navegación
Explore la biblioteca por tarea y caso de uso. En esta etapa, todos los enlaces conducen a la base de datos oficial curada:

*   [**✨ Búsqueda de prompts por IA (NUEVO)**](https://datvex.github.io/Datvex-prompt-LAB/) – Búsqueda inteligente impulsada por IA para encontrar rápidamente los prompts perfectos para sus necesidades.

## 🚀 Hoja de ruta (Roadmap)
Estamos evolucionando constantemente para ofrecer los mejores recursos de prompting.

- [x] **Fase 1:** Lanzamiento de la base de datos oficial curada (Actual).
- [ ] **Fase 2:** Expansión de categorías y plantillas avanzadas de ingeniería de prompts.
- [ ] **Fase 3:** **Base de datos comunitaria.** Se añadirá un espacio dedicado para que los usuarios compartan, prueben y almacenen sus propios prompts.
