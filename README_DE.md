# Datvex prompt LAB

Willkommen im **Datvex prompt LAB**. Dies ist ein professionelles, strukturiertes Repository, das hochwertige englischsprachige Prompts enthält, die für spezialisierte Aufgaben in verschiedenen KI-Systemen entwickelt wurden.

Die Sammlung umfasst sorgfältig kuratierte Prompts aus verschiedenen Quellen der globalen KI-Community – einschließlich GitHub-Repositories, Discord-Kanälen und anderen professionellen Ressourcen – sowie Original-Prompts, die speziell für dieses LAB entwickelt wurden.

---

## 📂 Navigation
Durchsuchen Sie die Bibliothek nach Aufgabe und Anwendungsfall. Zum jetzigen Zeitpunkt führen alle Links zur offiziellen kuratierten Datenbank:

*   [**✨ KI-Prompt-Suche (NEU)**](https://datvex.github.io/Datvex-prompt-LAB/) – Intelligente KI-gestützte Suche, um schnell die perfekten Prompts für Ihre Bedürfnisse zu finden.

---

## 🚀 Roadmap
Wir entwickeln uns ständig weiter, um die besten Prompt-Ressourcen bereitzustellen.

- [x] **Phase 1:** Start der offiziellen kuratierten Datenbank (Aktuell).
- [ ] **Phase 2:** Erweiterung der Kategorien und fortgeschrittene Prompt-Engineering-Vorlagen.
- [ ] **Phase 3:** **Community-Datenbank.** Ein spezieller Bereich für Benutzer zum Teilen, Testen und Speichern eigener Prompts wird hinzugefügt.
