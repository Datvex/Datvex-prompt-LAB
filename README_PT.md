# Datvex prompt LAB

Bem-vindo ao **Datvex prompt LAB**. Este é um repositório profissional e estruturado que contém prompts de alta qualidade em inglês, projetados para tarefas especializadas em múltiplos sistemas de IA.

A coleção inclui prompts cuidadosamente selecionados de várias fontes da comunidade global de IA — incluindo repositórios do GitHub, canais do Discord e outros recursos profissionais — bem como prompts originais desenvolvidos especificamente para este LAB.

---

## 📂 Navegação
Navegue pela biblioteca por tarefa e caso de uso. Nesta fase, todos os links levam ao banco de dados oficial com curadoria:

*   [**✨ Busca de prompts por IA (NOVO)**](https://datvex.github.io/Datvex-prompt-LAB/) – Busca inteligente alimentada por IA para encontrar rapidamente os prompts perfeitos para suas necessidades.

---

## 🚀 Roadmap (Plano de Desenvolvimento)
Estamos evoluindo constantemente para fornecer os melhores recursos de prompting.

- [x] **Fase 1:** Lançamento do banco de dados oficial (Atual).
- [ ] **Fase 2:** Os usuários podem adicionar seus próprios prompts ao banco de dados.
- [ ] **Fase 3:** **Criação do gerador de prompts IA.** Desenvolvimento de uma ferramenta inteligente para gerar prompts com base nas suas necessidades.
